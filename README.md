# Révision Sfax

Petit tableau de bord local (HTML/JS, sans build) pour le workflow : blocs de travail calés sur Fajr, Dhuhr, Asr, Maghrib, Isha.

## Lancer

Double-clique `index.html` (aucun serveur, aucun npm).

## Utiliser avec Cursor

1. Ouvre ce dossier dans Cursor.
2. Quand le tableau de bord affiche un **BLOC**, copie le prompt.
3. Chat : `Ctrl+L`, colle, et cible `@cours-exemple.md` (ou tes vrais cours).
4. BLOC 2 : crée `tp_revision.js`, sélectionne, `Ctrl+K`.
5. À Isha : stop. Pas de 5e bloc « encore 10 minutes ».
